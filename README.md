# مبيد دراما × فلمها أكثر — v3

واجهة عربية PWA مجانية بزرين للكوميديا، مع تحذير أكسجين الدراما. الحد المطلوب للنص المولد 10 سطور. اختيار المخاطبة محايد افتراضياً.

**مهم:** هذه النسخة لا تحتوي على نموذج ذكاء اصطناعي. الزر يجهّز تعليمات منفصلة لكل وضع ثم يمكن نسخها إلى نموذج خارجي. لا ترسل المواقف آلياً، ولا تتطلب مفتاحاً أو فاتورة.

## تشغيل محلي

من داخل المجلد: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`. التثبيت كـ PWA يحتاج HTTPS أو localhost.

## نشر مجاني

ارفع محتويات المجلد إلى GitHub Pages من المستودع الخاص بك (Settings → Pages → Deploy from a branch → main /(root)). لن يعمل التوليد المباشر حتى يتم تركيب محرك فعلي آمن لاحقاً.
