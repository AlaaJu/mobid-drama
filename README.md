# مبيد دراما × فلمها أكثر — نسخة النشر

تطبيق PWA عربي مجاني للاستخدام الخيري.

## النشر على GitHub Pages
ارفع الملفات الموجودة بجانب هذا الملف إلى جذر المستودع، ثم Settings → Pages → Deploy from a branch → main → /(root).

## حدود النسخة
لا تحتوي على API أو نموذج توليدي؛ تنشئ تعليمات يمكن نسخها واستخدامها مع ChatGPT. لا ترسل القصص تلقائياً.

أزلنا مثال القصة الشخصية من الصفحة قبل النشر.
